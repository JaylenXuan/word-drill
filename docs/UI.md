# 界面改造记录（Batch 1–4）

给未来的自己看：为什么这么改、改了哪些文件、哪些是有意为之。

## 目标

原界面干净但「不想每天打开」。改造目标是**温度**，不是加装饰。

三条原则：
1. 可爱住在细节里（圆角、阴影、回弹、数字跳动），不住在贴纸上
2. 角色要稀有：一天只见一次，天天见会腻
3. 学习区绝对安静：单词卡正反面不出现角色、花纹、动效背景

## 配色

两套，同一套设计语言：

| | 浅色「海盐奶油」 | 深色「深海夜航」 |
|---|---|---|
| 底 | `#FBF9F5` | `#141A2B` |
| 卡片 | `#FFFFFF` | `#1D2438` |
| 主色 | `#5B8FD1` | `#7FA8E8` |
| 主按钮 | `#3F6FB0` + 白字 | `#7FA8E8` + 深字 |
| 强调 | 脸颊粉 / 围裙金 | 同左，提亮 |

颜色全部从角色身上取。所有色值集中在 `src/styles.css` 顶部的 `:root` 与
`@media (prefers-color-scheme: dark)` 两块，组件里不写死颜色。

## 对比度

**26 组文字/底色对全部 ≥ WCAG AA**（正文 4.5:1，大字号 3:1）。
这一条写进了测试：`node tests/run.mjs` 会直接读 `styles.css` 的变量重算，
改坏了就红。

修过的问题（第一版全都不达标）：

| 问题 | 原值 | 改法 |
|---|---|---|
| 次要文字 | 3.81:1 | `--text-muted` 加深到 `#646A78`（5.15） |
| 主按钮白字 | 3.34:1 | 单独拆出 `--cta` 深蓝（5.11） |
| 「认识」白字 | 2.87:1 | 单独拆出 `--ok-btn` 深绿（4.96） |
| 连击天数 | 2.25:1 | 拆出 `--gold-ink`（5.37） |
| 选中态文字 | 3.34:1 | 拆出 `--accent-text`（6.49） |
| 深色主按钮 | 2.42:1 | 深色模式反过来：浅蓝底 + 深字（7.51） |

教训：**「填充色」和「文字色」不能共用一个变量**。粉、金、蓝当背景好看，当文字就糊。

## 鲸鱼娘

只出现在 3 处，且都远离学习区：

| 位置 | 尺寸 | 动效 |
|---|---|---|
| 完成页 | 148px | 上下浮动 3.4s，只动 `transform` |

## 动效清单

| 交互 | 效果 | 时长 |
|---|---|---|
| 卡片翻面 | 3D rotateY | 460ms |
| 按钮按压 | scale 0.972 | 140ms |
| 答「不认识」 | 卡片左右抖 + 底部水花环 | 260ms / 420ms |
| 完成页 | 数字依次弹入 | 460ms（间隔 70ms） |
| 进度条 | 宽度过渡 + 末端小圆点 | 500ms |

全部只动 `transform` / `opacity`，不触发重排；`prefers-reduced-motion: reduce`
时统一降到 0.001ms。

## 提示音

Web Audio 现场合成，零音频文件。三个音：认识（上行两音）、模糊（单音）、
不认识（下行低音）。音量 0.05–0.06，开关在「我的 → 偏好」。
偏好存独立 key `vocab.ui`，**不写进 `vocab.v1/state`**。

## 有意为之的取舍

- **答错后等 260ms 才进下一张**：不加这个延迟就看不到抖动。期间锁住评分防连点。
- **tabbar 去掉了毛玻璃**：`backdrop-filter` 在 iPhone 滚动时掉帧，换成纯色 + 1px 边框。
- **首页不放常驻小头像**：22–28px 的角色缩略图在视网膜屏上是糊的，宁可不放。
- **不做震动反馈**：iOS Safari 不支持 Vibration API。
- **不做全屏彩带**：几十个 DOM 每帧重绘，每天触发一次，性价比极低。
